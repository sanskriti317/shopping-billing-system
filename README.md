# Shopping Billing System (C)

A console-based billing application built in C, developed as a group project.

## Features
- Multi-category product menu (Food, Electronics, Makeup, Toiletries, Stationary)
- Shopping cart with add/remove items
- Automatic tax calculation per category
- Coupon code system (percentage discounts)
- Distance-based delivery charge calculator
- Payment options: UPI (with ID validation) and Cash on Delivery
- Customer delivery address input
- Order rating/feedback system
- Final itemized bill generation

## Tech Used
- Language: C
- Concepts: Structs, functions, arrays, string handling, input validation
